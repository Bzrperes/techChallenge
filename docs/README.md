
# Documentação do projeto

Esta pasta reúne os documentos técnicos do Tech Challenge Fase 1, desenvolvido para previsão de churn de clientes de uma operadora de telecomunicações.

## Documentos

| Arquivo | Descrição |
|---|---|
| [ML_CANVAS.md](./ML_CANVAS.md) | Definição do problema de negócio, objetivos, stakeholders, dados, métricas e limitações do projeto. |
| [MODEL_CARD.md](./MODEL_CARD.md) | Informações sobre o modelo escolhido, resultados, limitações e possíveis vieses. |
| [ALTERACOES.md](./ALTERACOES.md) | Decisões técnicas realizadas durante a integração do modelo com a API. |
| [VALIDACAO.md](./VALIDACAO.md) | Registro dos testes, verificações realizadas e limitações identificadas. |

## Documentação complementar

Os notebooks e o código do projeto estão disponíveis nas seguintes pastas:

- `notebooks/`: análise exploratória, treinamento e comparação dos modelos.
- `src/`: pré-processamento, inferência e implementação da API FastAPI.
- `tests/`: testes automatizados.
- `models/`: pipeline do modelo final.

As instruções de instalação, execução e utilização da API estão disponíveis no [README principal](../README.md).
