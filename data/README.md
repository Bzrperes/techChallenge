# Dados

O dataset **Telco Customer Churn — IBM** é baixado diretamente do Kaggle pelo notebook, usando o pacote `kagglehub`.

O arquivo bruto não precisa ser armazenado no repositório: cada integrante pode reproduzir o download depois de configurar sua credencial do Kaggle no arquivo `.env` da raiz do projeto.

Arquivos de dados derivados que forem necessários em etapas futuras deverão ter sua origem e seu processo de geração documentados antes de serem adicionados a esta pasta.
